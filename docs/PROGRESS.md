## 검증 도구
- `verify/verify_turns.py --n 600 --runs 100 --turns 4 --switch 0.15 --seed S --snap 32` : 시나리오 생성(교체 확률 `--switch`) + Showdown 대조.
- `verify/focus_cases.py <weather|terrain|screens|knockoff|sleeptalk|all> [n] [runs] [turns] [seed] [switch]` : 특정 상호작용만 집중해서 Showdown 과 분포 대조 (날씨 겹침/날씨 바위/메가리자몽Y/구름의 무게/캐스퐁, 필드 특성·씨앗·지속 증가 도구, 빛의장막·오로라베일·빛의점토·벽 부수기, 탁쳐서떨구기·던지기·도둑질·수확·긴장감, 잠자기/잠꼬대/울부짖기/날려버리기). 결과 JSON 은 `verify/out/focus_*` 에 따로 저장.
- `verify/sweep.sh "1턴 시드들" "2턴 시드들" "깊은 시드들"` : 여러 시드를 연달아 실행하고 불일치 파일을 `verify/out/sweep/` 에 보관. 환경변수 `SNAP` 로 스냅샷 지정(기본 32).
  - **스윕이 도는 동안 같은 출력 파일을 쓰는 `verify_turns.py` 를 따로 돌리지 말 것.**
- 한 시나리오 분석: 불일치 JSON 에서 시나리오를 읽어 앞 N 턴만 잘라 비교하면 처음 갈라지는 턴을 찾을 수 있다 (우리/Showdown 로그를 나란히 보고, 분포가 다르면 400회 표본으로 확인).
- 스냅샷 번호는 DB 구축 때 자동 증가라 환경마다 다를 수 있다 (이번 구축은 32 = gen9championsbssregmc 2026-09 컷오프 1760).

## 클라우드 세션에서 환경 만들기
- 필요한 외부 호스트: `play.pokemonshowdown.com`, `pokeapi.co`, `pokemondb.net`, `www.smogon.com`, `www.serebii.net` (환경의 Network access 에 허용).
- 순서: MySQL 8 설치/기동 → `pip install -r requirements.txt numpy scipy` → Showdown 클론/빌드 → `DB_PASSWORD=... python etl/build_all.py pokemon` (캐시가 있으면 4분, 처음엔 ZA 크롤링 때문에 약 15분).
- 세션이 끝나면 컨테이너가 사라지므로 위 과정을 환경의 setup script 에 넣어 둘 것. MySQL 서비스가 자동으로 유지되지 않으니 접속 확인 후 시작.

## 이번 라운드(v2)에서 맞춘 규칙 (Showdown 대조로 발견)
- 챔피언스 모드 규칙: 수면 [2,3,3], 마비 행동불가 1/8, 얼음 25% 해동 + 3회 상한, 프리즈드라이 얼음 효과 없음(재정의 기술은 챔피언스 행이 없으면 효과 없음), 재정의 기술 9개.
- 상태/지속: 앙코르(4턴, 이미 움직였을 때; 고정 기술 저장), 봉인, 힐블록(회복 기술 선택 불가), 속박 5~6턴, 순풍 갱신 불가, 난동류 잠금 해제 규칙, 혼란 자해 공식(위력 40)과 33%, Destiny Bond 상태.
- 새로 구현: 멸망의노래, 미래예지, 매직룸, 봉인, 따라하기, 퀵가드/와이드가드 + 연속 보호 카운터, 메트로놈 도구, 벌레먹기/쪼기, 스틸롤러/아이스스피너(필드 제거), Baton Pass 가 넘기는 상태 확장.
- 순서/시점: 턴 종료 효과를 종류별 두 패스로 처리, 날씨 → 미래예지 → 소원, 열매는 부가효과 뒤에 판단, 쓰러진 뒤 교체 반복(해저드 사망 포함), 동시 쓰러짐 교체 순서, 폼 체인지 시점, 변장 깨짐 유지, 막힌 기술은 실패가 아님, 회복 반올림(고정 비율 반올림 / 날씨 회복 4096 고정소수점).

## 2시간 라운드에서 추가로 맞춘 규칙 (깊은 시나리오 + 집중 검증)
- 날씨: 구름의 무게/에어록은 날씨 효과만 무효화(날씨는 유지), 캐스퐁 Forecast 타입 변화, 같은 날씨를 다시 깔아도 지속 시간 갱신 없음(특성), 필드도 동일, 날씨 → 미래예지 → 소원 → 필드/도구 → 씨뿌리기 → 독/화상 순으로 효과 종류별 처리.
- 벽: 오로라베일은 같은 분류의 리플렉터/빛의장막이 있으면 따로 적용되지 않음, 벽 부수기는 타입 면역이면 발동하지 않음, 빛의점토 8턴.
- 도구: 선제공격손톱(20%), 기합의머리띠(10%), 던지기(위력·열매·상태이상·풀죽음, 막히거나 빗나가도 소비), 도둑질/탐내기(접촉 반격 뒤, 열매 소비 앞), 수확(맑으면 확실 / 50%, 던져서 맞은 열매는 기록 안 함), 긴장감(Unnerve)이 열매를 막고 사라지면 다시 판정, 열매 Update 는 행동/턴 종료 뒤, 트릭으로 받은 상태이상 열매 즉시 사용, 구애 고정 해제(트릭/도구 상실).
- 잠꼬대 구현, 수면 중 난동부리기 잠금은 턴 종료에 해제, 난동부리기류는 막힘/빗나감/풀죽음/봉인/대상 없음일 때도 잠금 종료 시 혼란, 충전·난동 잠금 중 교체 불가.
- 기타: 틀깨기가 방어 특성(거울갑옷/심술꾸러기/단순)을 무시, 아군 대상 기술은 싱글에서 실패, 소리 기술 면역(방음/방탄), 대타를 무시하는 능력 하락, 씨뿌리기 회복은 실제 감소량, 방어류 연속 카운터는 한 턴 쉬면 초기화, 쓰러지면 능력 단계 초기화, 트레이스/특성교환 복원, 동시 교체 시 등장 효과는 현재 속도 순.
